A small note on readable sports heatmaps

Heatmaps are attractive, but colour alone is not enough. I keep the raw value available on focus and tap, use a legend with explicit endpoints, and avoid a palette where adjacent values are impossible to distinguish.

Mobile inspection

Hover-only tooltips disappear on phones, so each cell also responds to tap and keyboard focus. Fixed aspect ratios prevent the chart from resizing when a tooltip opens.

The reference implementation is this NBA heatmap tool.

Data boundaries

The title and legend should state the season, metric, and population being compared. Without those three pieces, a polished chart can still communicate the wrong conclusion.
