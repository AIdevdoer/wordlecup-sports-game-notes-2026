Turning an impossible season target into a short browser game

The 38 win idea works because the goal is instantly understandable: build a squad that can survive a full league season without dropping points. The interface has to turn that exaggerated target into a series of quick, readable choices.

Keep the decision loop visible

Each pick should show what changed and why. Hiding the scoring model makes the challenge feel arbitrary. I expose role balance and the main squad constraints while keeping the final outcome uncertain.

The playable reference is 38-0, the browser football squad challenge.

Short sessions, clear restarts

The round should finish in a few minutes, provide a compact season result, and let the player restart without reloading a heavy page. A share card should describe the record without revealing every squad choice.

Published as a public implementation note. The linked game is the working reference build.
